# 🤝 Contributing to Table To Chart

Thanks for helping improve `table-to-chart`.

---

## 🐞 Bugs and feature requests

Please open a GitHub issue for:

- bugs or regressions
- chart rendering problems or unexpected output
- feature ideas or polish requests
- documentation fixes

Include your workflow config, a sample of the markdown table, and the error output when possible.

---

## 🔀 Pull requests

PRs are welcome.

Please:

1. open an issue first for larger changes
2. keep PRs focused and easy to review
3. update docs when behavior changes
4. avoid committing local-only files such as `CLAUDE.md`, `NOTES.md`, or personal config

---

## 👀 Review flow

This repo uses code ownership so **`@Godimas101`** is automatically requested for review on pull requests.
